# Symcio 模板 Layout 規格參考

## 基本設計規格

| 屬性 | 值 |
|------|------|
| 尺寸 | 1440 × 810 px（16:9 橫式） |
| 來源工具 | Canva |
| 主色 | 深綠 `#1B4332`（背景、Tag、強調） |
| 底色 | 米灰 `#F0EDE8`（內容頁底色） |
| 輔助色 | 白 `#FFFFFF`（深色底上的文字）、深綠文字（淺底頁） |
| 強調色 | 紅 `#C1121F`（警示/對比數字）、金綠 `#6B8E23`（次要標籤） |
| 中文字型 | **Noto Sans TC**（思源黑體）— 所有中文段落一律使用 |
| 英文字型 | 保留原檔英文字型不動 |
| 左上角 Tag | 每頁固定有深綠色矩形標籤（如「市場問題」「解決方案」等），白字 |
| 右上角 Logo | Symcio 雙括號 Logo `Ʂ`，深綠或白色依底色切換 |
| 底部裝飾 | 部分頁面有綠色漸層霧化邊緣（左下、右下） |

## Layout A — 封面頁 (Hero Cover)

**原始頁碼：** P1, P18

**結構：**
```
┌──────────────────────────────────────────┐
│ @SYMCIO.TW               [全識 Logo]     │ ← 深綠底 + 世界地圖半透明
│                                          │
│         ██ 大標題（2行）██               │ ← 白色粗體，居中偏上
│                                          │
│  [左側豎排文字]   [中央 Mockup]  [右側豎排] │
│                                          │
│         副標說明文字（3-4行）              │ ← 白色小字，居中
│                                          │
│ www.symcio.tw        [tagline]    碳智IP  │ ← 底部資訊列
└──────────────────────────────────────────┘
```

**用途：** 封面、結尾頁、品牌宣言頁
**文字容量：** 大標 ≤12字×2行，副標 ≤4行×30字
**可選元素：** 中央 Mockup（手機/Logo），左右豎排短語，底部網址列

```
│ [Tag] 大標題          │                   │
```

## Layout C — 三欄等分 Icon 卡 (3-Column Icon Grid)

**原始頁碼：** P3, P6

**結構：**
```
┌──────────────────────────────────────────┐
│ [Tag]  大標題橫跨全寬                     │
│                                          │
│  [Icon1]       [Icon2]       [Icon3]     │
```

## Layout F — Venn 圖 / 同心圓 (Venn / Concentric)

**原始頁碼：** P9, P12

**結構（Venn 三圈）：**
```
┌──────────────────────────────────────────┐
│ [Tag]  大標題                    [Logo]   │
│                                          │
│        [外部標籤←]  ○○○  [→外部標籤]      │
│                    ○○○                   │
│  [外部標籤]         ○○○    [外部標籤]     │ ← Venn 三圈交疊
│                    ○○○                   │
│        [外部標籤←]  ○○○  [→外部標籤]      │
│                                          │
└──────────────────────────────────────────┘
```

**結構（同心圓 TAM/SAM/SOM）：**
```
┌──────────────────────┬───────────────────┐
│ [Tag]  大標題         │                   │
│                      │                   │
│    ┌─────────┐       │  TAM 說明          │
│    │ ┌─────┐ │       │                   │
│    │ │┌───┐│ │       │  SAM 說明          │
│    │ ││SOM││ │       │                   │
│    │ │└───┘│ │       │  SOM 說明          │
│    │ └─────┘ │       │                   │
│    └─────────┘       │                   │
└──────────────────────┴───────────────────┘
```

**用途：** 商業模式（Venn）、市場規模（同心圓）
**文字容量：** Venn 外部標籤各 ≤8字，同心圓右側說明各 ≤3行
**變體：**
- F1（P9）：三圈 Venn + 外圍箭頭標籤
- F2（P12）：左同心圓 + 右文字說明（TAM/SAM/SOM）

## Layout J — 三欄人物卡 (Team Profile Cards)

**原始頁碼：** P15

**結構：**
```
┌──────────────────────────────────────────┐
│ [Tag]  大標題                             │
│                                          │
│ ┌──────────┐ ┌──────────┐ ┌──────────┐  │
│ │ [照片]    │ │ [照片]    │ │ [照片]    │  │ ← 深綠底圓角卡
│ │          │ │          │ │          │  │
│ │ " 引號   │ │ " 引號   │ │ " 引號   │  │
│ │ 經歷描述  │ │ 經歷描述  │ │ 經歷描述  │  │ ← 白字 ≤5行
│ │          │ │          │ │          │  │
│ │ ██ 姓名  │ │ ██ 姓名  │ │ ██ 姓名  │  │
│ │ 職稱     │ │ 職稱     │ │ 職稱     │  │
│ └──────────┘ └──────────┘ └──────────┘  │
└──────────────────────────────────────────┘
```

**用途：** 團隊介紹、顧問委員、合作夥伴
**文字容量：** 每張卡片經歷 ≤50字，姓名+職稱各1行
**彈性規則：** 如只有2人→用2欄；如只有1人→改用其他 Layout
**⚠️ 刪除規則：** 用不到的卡片欄位整個刪除（含照片框+引號+文字+姓名），不留空白卡
